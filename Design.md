# Design Guidelines

## Theme
- Mode: Light / Dark / Both (toggle)
- Style direction: Modern, clean, minimal, and student-friendly

## Color Palette
- Primary: #2563EB
- Secondary: #7C3AED
- Background: #F8FAFC
- Background (dark): #0F172A
- Text (primary): #0F172A
- Text (secondary): #475569
- Accent: #10B981
- Success: #22C55E
- Error: #EF4444
- Warning: #F59E0B

## Typography
- Font family: Inter, Poppins, sans-serif
- Headings:
  - H1: 32px / 700 / 1.2
  - H2: 24px / 600 / 1.3
  - H3: 20px / 600 / 1.3
  - H4: 18px / 600 / 1.3
  - H5: 16px / 600 / 1.3
  - H6: 14px / 600 / 1.3
- Body text: 16px / 400 / 1.6
- Small text: 14px / 400 / 1.5

## Spacing & Layout
- Base spacing unit: 8px grid system
- Section spacing: 24px / 32px
- Container max-width: 1200px
- Border radius standard: 12px
- Card radius: 16px

## Components Style
- Buttons:
  - Primary: filled blue, rounded, medium padding
  - Secondary: outlined or soft background
  - Hover: slightly darker or brighter shade
  - Disabled: reduced opacity
- Cards:
  - White/light surface with subtle shadow
  - Rounded corners and clear padding
- Inputs:
  - Clean border, focus ring in primary color
  - Rounded corners
- Modals:
  - Centered, soft shadow, clear header/body/footer separation

## Icons
- Icon set: Lucide React
- Style: outline-based, consistent stroke width

## Tone/Voice
- Friendly, motivating, and professional
- Clear and concise UI copy
- Encouraging for learning and progress
